# Frontend design

Read [DESIGN.md](DESIGN.md) before making visual or UI changes.
Use the semantic tokens in `apps/web/src/styles/tokens.css` and primitives from `@/components/ui`.
Keep typography, spacing, focus states, and semantic colors consistent with the design system.
The live component reference is `/design-system`; update it when changing shared components.
During visual QA, check desktop and mobile layouts and both preview themes.
Do not replace the established design direction without explicit user approval.
